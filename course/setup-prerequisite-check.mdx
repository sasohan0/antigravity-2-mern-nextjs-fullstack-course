# Module 0: Setup & Prerequisite Check


## Purpose

This module prevents tool blockers during the Eid learning sprint. Students must confirm that their machine, accounts, GitHub workflow, Antigravity access, NotebookLM workflow, Figma inspection, MongoDB Atlas, and deployment accounts are ready.

## Required accounts

- Google account
- GitHub account
- Figma account
- MongoDB Atlas account
- Vercel account
- Render account
- NotebookLM access
- Google Antigravity access

## Required software

- Google Chrome
- Google Antigravity
- Node.js LTS
- npm
- Git
- Postman, Thunder Client, Insomnia or Hoppscotch
- Figma desktop or browser access

## Terminal readiness check

```bash
node -v
npm -v
git --version
```

## GitHub readiness check

Create a test repository named `antigravity-setup-check`, then practice `git init`, `git add`, `git commit`, remote setup, and push.

## Antigravity readiness check

Create a folder named `antigravity-setup-test` and ask Antigravity to read a README, create a checklist, and avoid installing packages.

## Figma readiness check

Open a free Figma Community file and confirm that you can inspect colors, font sizes, spacing, export/screenshot a frame, and copy a frame link.

## MongoDB Atlas readiness check

Confirm that your cluster, database user, secure password, network access, and connection string are ready.

## NotebookLM workflow

Create a notebook named after this module and add this page, the official docs, selected videos, and your project files.

Use this prompt:

```txt
Create a practical study guide for this module.

Audience:
Junior MERN developers using Antigravity and NotebookLM.

Output:
1. Key concepts
2. Simple explanations
3. Step-by-step practice workflow
4. Common mistakes
5. Submission checklist
6. 10 quiz questions with answers
```

## Antigravity safe prompt pattern

```txt
Read only:
- [exact file 1]
- [exact file 2]

Goal:
[exact task]

Rules:
- Do not modify unrelated files.
- Do not install packages without approval.
- Before editing, list files you will create or modify.
- After editing, summarize changes.
- Include verification steps.
```
