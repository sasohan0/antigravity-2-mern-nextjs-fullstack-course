# Introduction: What to Expect and How to Use This Course


## Course promise

This course trains junior MERN developers to use Antigravity like a disciplined engineering partner, not a magic code generator.

Students will learn to:

- Understand business requirements.
- Plan before coding.
- Create architecture and API contracts.
- Use `SKILL.md` files.
- Convert Figma/designs into React UI.
- Build frontend and backend separately.
- Integrate APIs.
- Test, deploy and package the project.
- Present the project in portfolio and interviews.

## How to consume every module

1. Read the module.
2. Add module sources to NotebookLM.
3. Watch the controlled video layer.
4. Generate Study Guide, Mind Map, Quiz and Video Summary.
5. Complete practice missions.
6. Submit evidence.
7. Apply mentor feedback.

## Completion outcome

After the full course, students should be able to build and explain a deployed MERN capstone using AI-assisted development discipline.

## NotebookLM workflow

Create a notebook named after this module and add this page, the official docs, selected videos, and your project files.

Use this prompt:

```txt
Create a practical study guide for this module.

Audience:
Junior MERN developers using Antigravity and NotebookLM.

Output:
1. Key concepts
2. Simple explanations
3. Step-by-step practice workflow
4. Common mistakes
5. Submission checklist
6. 10 quiz questions with answers
```

## Antigravity safe prompt pattern

```txt
Read only:
- [exact file 1]
- [exact file 2]

Goal:
[exact task]

Rules:
- Do not modify unrelated files.
- Do not install packages without approval.
- Before editing, list files you will create or modify.
- After editing, summarize changes.
- Include verification steps.
```
