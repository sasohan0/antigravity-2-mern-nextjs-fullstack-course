# Module 10: Deployment and Portfolio Packaging


## Module purpose

Deploy frontend/backend, configure MongoDB Atlas and env vars, run smoke tests, prepare README, screenshots and final submission package.

## What students will be able to do

- Explain the module concept clearly.
- Use Antigravity safely with scoped prompts.
- Use NotebookLM to study resources and generate quizzes/mind maps.
- Complete practical deliverables.
- Submit evidence for mentor review.

## NotebookLM workflow

Create a notebook named after this module and add this page, the official docs, selected videos, and your project files.

Use this prompt:

```txt
Create a practical study guide for this module.

Audience:
Junior MERN developers using Antigravity and NotebookLM.

Output:
1. Key concepts
2. Simple explanations
3. Step-by-step practice workflow
4. Common mistakes
5. Submission checklist
6. 10 quiz questions with answers
```

## Antigravity safe prompt pattern

```txt
Read only:
- [exact file 1]
- [exact file 2]

Goal:
[exact task]

Rules:
- Do not modify unrelated files.
- Do not install packages without approval.
- Before editing, list files you will create or modify.
- After editing, summarize changes.
- Include verification steps.
```

## Practice missions

### Practice Mission 1: Prepare deployment

Create deployment plan, env checklist and production readiness checklist.

### Practice Mission 2: Deploy backend and frontend

Deploy backend to Render and frontend to Vercel or equivalent.

### Practice Mission 3: Package portfolio

Create README, screenshots, demo credentials, smoke test report and interview explanation.
