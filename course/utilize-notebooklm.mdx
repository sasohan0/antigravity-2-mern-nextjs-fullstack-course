# Utilize NotebookLM: Study Faster with Docs, Videos and Project Files


## Purpose

NotebookLM acts as the student learning layer. It should not replace practice, but it helps students understand official docs, videos, and their own project files.

## Required NotebookLM outputs per major module

- Study Guide
- Mind Map
- Video Learning Summary
- Flashcards or Quiz
- Audio Overview if available
- Confusing topic explanation
- Submission checklist

## Universal NotebookLM prompt

```txt
Create a beginner-friendly guide from these sources.

Audience:
Junior MERN stack developers learning with Antigravity.

Output:
1. Key concepts
2. Simple explanation
3. Practical examples
4. Common mistakes
5. Practice tasks
6. Quiz questions with answers
7. Checklist before submission
```

## Video summary prompt

```txt
I added videos for this module.

Create a video learning summary:
1. Main lessons
2. What to apply in my project
3. Common mistakes
4. 5 action tasks
5. 5 questions to self-check
```

## NotebookLM workflow

Create a notebook named after this module and add this page, the official docs, selected videos, and your project files.

Use this prompt:

```txt
Create a practical study guide for this module.

Audience:
Junior MERN developers using Antigravity and NotebookLM.

Output:
1. Key concepts
2. Simple explanations
3. Step-by-step practice workflow
4. Common mistakes
5. Submission checklist
6. 10 quiz questions with answers
```

## Antigravity safe prompt pattern

```txt
Read only:
- [exact file 1]
- [exact file 2]

Goal:
[exact task]

Rules:
- Do not modify unrelated files.
- Do not install packages without approval.
- Before editing, list files you will create or modify.
- After editing, summarize changes.
- Include verification steps.
```
