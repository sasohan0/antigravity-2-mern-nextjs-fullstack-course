# Instructor / Mentor Delivery Guide


## Recommended 7-day launch sprint

| Day | Focus |
|---|---|
| Day 0 | Setup and orientation |
| Day 1 | Introduction + Modules 1–2 |
| Day 2 | Modules 3–4 |
| Day 3 | Module 5 + Bonus 5.5 |
| Day 4 | Module 6 |
| Day 5 | Module 7 |
| Day 6 | Modules 8–9 |
| Day 7 | Module 10 + Final assignment briefing |

## Daily routine

1. Morning: share module goal.
2. Midday: collect blockers.
3. Evening: collect submissions.
4. Night: publish common fixes.

## Feedback format

```txt
Status: Green / Yellow / Red / Blocked

Strong points:
1.
2.

Critical fixes:
1.
2.

Next action:
-

Deadline:
-
```

## Mentor review levels

| Status | Meaning |
|---|---|
| Green | Complete and ready |
| Yellow | Usable but needs fixes |
| Red | Missing major deliverables |
| Blocked | Tool/setup issue preventing progress |
