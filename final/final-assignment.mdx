# Final Assignment: Category-Based Real-World Figma-to-MERN Capstone


## Assignment purpose

This capstone simulates a real company assignment. Students choose one category, use a Figma/design source, plan the app, create architecture docs, build frontend/backend, integrate APIs, test, deploy and present.

## Category options

| Category | Main resource | Required user action | Admin/provider work |
|---|---|---|---|
| Food delivery | Food item | Order food | Manage foods and orders |
| Event booking | Event | Book ticket | Manage events and bookings |
| E-learning | Course | Enroll/learn | Manage courses/modules |
| Fitness/appointment | Provider | Book appointment | Manage availability/appointments |
| Finance tracker | Transaction | Add transaction/budget | Manage categories/users |
| Real estate | Property | Save/inquire | Manage listings/inquiries |

## Minimum project scope

- At least 7 frontend pages
- At least 3 backend models
- Authentication
- Protected user route
- Protected admin/provider route
- CRUD for main resource
- Search/filter
- Dashboard/management panel
- Loading, empty, error and success states
- Real database connection
- API integration
- Testing
- Deployment
- Professional README

## Final workflow

1. Choose category and design source.
2. Create project brief and planning docs.
3. Create architecture and design handoff docs.
4. Build frontend with mock data.
5. Build backend APIs.
6. Integrate frontend and backend.
7. Test and verify user/admin flows.
8. Deploy.
9. Write README and final submission.
10. Prepare interview explanation.
