# Contributing

## Contribution workflow

1. Create an issue.
2. Create a branch.
3. Edit content or code.
4. Run local build.
5. Open a pull request.
6. Complete the PR checklist.

## Branch names

```txt
docs/module-05-update
feat/quiz-module-08
fix/sidebar-link
chore/seo-readme
```

## Commit style

```txt
docs: improve module 5 figma workflow
feat: add module 8 quiz questions
fix: correct deployment instructions
chore: update docusaurus config
```

## Local checks

```bash
npm install
npm run typecheck
npm run build
```
