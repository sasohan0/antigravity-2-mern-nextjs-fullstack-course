# Bonus Module: Reusable SKILL.md Library


## Purpose

This module turns Antigravity from a one-project tool into a reusable AI development system.

## Recommended library structure

```txt
my-agent-skills-library/
  README.md
  SKILL_LIBRARY_INDEX.md
  CHECKLISTS/
    skill-authoring-checklist.md
    skill-safety-checklist.md
    skill-testing-checklist.md
    copy-skill-into-project-checklist.md
  templates/
    basic-skill-template.md
    review-skill-template.md
    implementation-skill-template.md
    verification-skill-template.md
  skills/
    planning/prd-generator/SKILL.md
    architecture/mern-architecture-review/SKILL.md
    frontend/react-ui-polish/SKILL.md
    backend/express-api-quality/SKILL.md
    testing/test-plan-generator/SKILL.md
    deployment/portfolio-readme-generator/SKILL.md
```

## Universal SKILL.md template

```md
---
name: reusable-skill-name
description: Use this skill when [specific situation]. Do not use for [clear non-use case].
---

# Skill Title

## Goal
...

## When to Use
...

## Required Inputs
...

## Workflow
1. Read required inputs.
2. Create plan.
3. List files to change.
4. Execute only requested scope.
5. Verify.
6. Summarize.

## Constraints
- Do not expose secrets.
- Do not modify unrelated files.
- Do not install packages without approval.

## Output Format
1. Summary
2. Files reviewed
3. Plan
4. Risks
5. Verification steps
6. Final verdict
```

## NotebookLM workflow

Create a notebook named after this module and add this page, the official docs, selected videos, and your project files.

Use this prompt:

```txt
Create a practical study guide for this module.

Audience:
Junior MERN developers using Antigravity and NotebookLM.

Output:
1. Key concepts
2. Simple explanations
3. Step-by-step practice workflow
4. Common mistakes
5. Submission checklist
6. 10 quiz questions with answers
```

## Antigravity safe prompt pattern

```txt
Read only:
- [exact file 1]
- [exact file 2]

Goal:
[exact task]

Rules:
- Do not modify unrelated files.
- Do not install packages without approval.
- Before editing, list files you will create or modify.
- After editing, summarize changes.
- Include verification steps.
```
