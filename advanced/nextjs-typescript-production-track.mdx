# Advanced Module: Next.js + TypeScript Production Track


## Purpose

This advanced module teaches students how to move from classic MERN into modern full-stack TypeScript with Next.js App Router.

## Recommended project

**SkillBridge Pro** — a talent marketplace / mentorship platform.

Roles:

- Student/User
- Mentor/Service Provider
- Admin

Required pages:

- Home
- Mentor/service listing
- Details page
- Login/register
- Student dashboard
- My bookings
- Submit project review
- Mentor dashboard
- Admin dashboard
- Manage users/services/bookings

## Key mental models

### Server Components

Use for data fetching, database reads, server-only logic and mostly static UI.

### Client Components

Use for state, event handlers, browser APIs, modals, interactive filters and form UI.

### Route Handlers

Use for API-style endpoints, webhooks, external clients and custom request/response control.

### Server Actions

Use for forms and mutations inside the app, but always verify auth and authorization server-side.
